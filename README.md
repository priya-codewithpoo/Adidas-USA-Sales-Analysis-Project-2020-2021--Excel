# 📊 Adidas USA Sales Analysis Project (2020-2021)

![Dashboard Preview](2_Dashboard.png)

🔍 **Project Overview**
This project analyzes Adidas USA sales data (2020–2021) using Microsoft Excel to evaluate regional performance, product profitability, and target achievement. The objective was to clean raw sales data and build an interactive dashboard for business performance tracking.

🎯 **Objectives**
* Clean and transform raw sales data using Power Query

* Analyze regional and product-level performance

* Compare Target vs Actual revenue

* Calculate Sales Per Capita using population data

* Build an interactive and refreshable Excel dashboard

🛠 **Tools & Technologies**
* Microsoft Excel

* Power Query – Data cleaning and transformation

* Pivot Tables – Aggregation and KPI calculation

* Formulas Used: INDEX/MATCH, IFS, Percentage calculations

* Slicers & Timeline Filters – Interactive dashboard filtering

📂 **Project Structure**
The project is contained within a single, highly-structured Excel Workbook. To maintain professionalism, the "Back-end" is separated from the "Front-end":

* **Dashboard**: Interactive front-end with KPIs and charts
* **cleaned_data**: Output from Power Query transformations
* **calculation**: Aggregated data used for charts
* **pivot data**: Supporting metrics like Sales Per Capita
* **Data Folder**: Original CSV files

📈 Key Analysis Performed

* Target vs Actual revenue comparison

* Regional sales and profit distribution

* Product category performance (Apparel vs Footwear)

* Sales channel analysis (Online, In-store, Outlet)

* Sales Per Capita to identify underperforming high-population regions

🧠 **Key Learnings**
* Automating ETL using Power Query instead of manual edits

* Building structured Pivot-based dashboards

* Designing user-friendly reporting interfaces

* Understanding the importance of normalized metrics like Sales Per Capita

🏁 **Conclusion**
This project demonstrates how Microsoft Excel can be used as a structured reporting and analytics tool. By combining data cleaning, aggregation, and interactive visualization, the dashboard provides meaningful business insights to support performance monitoring.
